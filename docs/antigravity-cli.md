# Antigravity CLI 연결

이 기능은 Windows 0.1.3 시험판에 포함됩니다.

## 사용하기

1. [Google 공식 안내](https://antigravity.google/download)에 따라 Antigravity CLI를 설치합니다.
2. 새 CMD에서 `agy`를 실행하고 구독한 Google 계정으로 로그인합니다. API 키는 필요하지 않습니다.
3. 픽셀 오피스의 환경 점검 → AI 설정에서 Antigravity를 포함한 사용 범위를 선택합니다.
4. 새 부서의 부장으로 Antigravity를 선택하거나, 허용된 팀의 팀장·팀원으로 사용할 수 있습니다. 기존 팀의 사용 AI 제한은 유지됩니다.
5. 처음 사용하는 작업 폴더는 앱의 폴더 접근 확인 카드에서 경로를 확인하고 허가 또는 거부합니다.

Windows에서 실행 파일을 찾지 못하면 `PIXEL_ANTIGRAVITY_EXE`에 `agy.exe` 전체 경로를 지정할 수 있습니다. 앱은 `.cmd` 연결 파일을 거치지 않고 실제 실행 파일을 실행합니다.

## 연결 방식

- Google 로그인은 Antigravity가 관리하는 Windows 로그인 저장소를 그대로 사용합니다. 로그인 파일을 프로젝트에 복사하지 않습니다.
- 멤버마다 별도 대화 번호를 저장하고, 다시 시작할 때 `agy --conversation <대화 번호>`로 이어갑니다. 원본 대화 기록은 Antigravity의 사용자 폴더에 저장됩니다.
- 프로젝트의 `.agents/hooks.json`과 `.agents/mcp_config.json`에 픽셀 오피스 항목을 추가합니다. 다른 항목은 보존하고, 이름이 겹치는 사용자 설정은 덮어쓰지 않고 알립니다.
- 공유 설정에는 멤버 식별 정보가 들어가지 않습니다. 각 실행의 환경변수로 해당 멤버의 팀 도구와 연결합니다.
- 시작할 때 `/mcp` 화면에서 팀 도구의 연결을 확인한 뒤 업무를 전달합니다. 이 확인에는 AI 질문을 보내지 않습니다.
- 작업 승인·거부는 원래 도구 실행 직전의 연결 신호로 전달합니다. 전체 허용 옵션은 사용하지 않습니다. 승인 카드에서 명령을 고쳐서 실행하는 기능은 지원하지 않으므로, 거부한 뒤 새 지시를 보내세요.
- 기존 부서의 승인 방식과 역할 제한을 적용합니다. 실행 환경을 확정할 수 없는 명령, `.agents`·`.gemini` 설정 편집은 자동으로 안전하다고 판단하지 않습니다.

## 확인한 범위

Windows의 Antigravity CLI 1.4.6과 Google AI Pro 계정에서 다음을 확인했습니다.

- 실제 모델 응답과 픽셀 오피스의 응답 기록.
- 승인한 시험 파일 생성, 거부한 시험 파일이 생성되지 않는 것.
- 팀 상태 조회와 실제 팀 보고 호출.
- 종료 후 같은 대화 번호로 다시 시작하고 이전 답변을 기억하는 것.
- 자동 검사에서 기존 데이터 유지, 여러 AI를 섞은 팀, 역할 제한, 명령 대기, 연결 준비 순서와 좁은 화면의 AI 선택.

사용량은 별도의 빈 확인용 폴더에서 `/usage` 화면만 열어 5분마다 조회합니다. AI에 질문하거나 진행 중인 멤버의 터미널에 입력하지 않습니다. Gemini, Claude·GPT, Gemini 4 Argon 등 CLI가 제공하는 그룹별 주간·5시간 한도와 갱신 시간을 표시합니다. 요약은 가장 적게 남은 한도를 기준으로 하며, 화면에서 제공하지 않는 갱신 시각은 추측하지 않습니다. 조회 실패 시 사용량 0이나 무제한으로 표시하지 않습니다. 계정 이메일과 로그인 정보는 사용량 데이터에 저장하지 않습니다. macOS·Linux 및 다른 CLI 버전의 실제 실행은 별도 확인이 필요합니다.
