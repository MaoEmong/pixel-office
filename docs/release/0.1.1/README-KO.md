# 픽셀 오피스 0.1.1 — Windows 사용 안내

Windows 0.1.1 시험판입니다. 중요한 프로젝트에 바로 적용하기 전에 복사본으로 사용해 보세요.

## 실행하기

1. Windows 10 또는 11의 64비트 PC에서 ZIP **전체**를 쓰기 가능한 폴더에 풉니다.
2. 압축을 푼 폴더의 `pixel_office.exe`를 실행합니다. ZIP 안에서 바로 실행하지 마세요.
3. `data`, `dev`, `runtime` 폴더와 DLL 파일을 함께 두세요. 실행 파일만 옮기면 작동하지 않습니다.

앱 실행에 필요한 Node.js, 내부 실행 프로그램, 기본 Windows 구성품은 포함되어 있습니다. Flutter, Visual Studio, Git, npm을 따로 설치할 필요는 없습니다.

배포본에는 실행에 필요한 파일과 외부 구성품만 포함합니다. 앱의 원본 개발 코드, 테스트와 개발 도구는 포함하지 않습니다.

아직 코드 서명을 하지 않은 시험판입니다. Windows에서 제작자를 확인할 수 없다는 안내가 나올 수 있습니다. 배포한 저장소와 ZIP의 SHA256 값이 일치하는지 확인하세요.

## AI 연결하기

AI 사용 계정과 사용할 AI의 명령 프로그램은 별도로 필요합니다. AI 사용료는 각 서비스의 조건을 따릅니다.

1. 사용할 프로그램을 공식 안내에 따라 설치하고 로그인하세요: [Claude Code](https://code.claude.com/docs/en/setup), [Codex CLI](https://developers.openai.com/codex/cli/).
2. 앱 상단의 `⋮ → 환경 점검 · CLI 로그인`을 엽니다.
3. `Claude Code만 사용`, `Codex만 사용`, `Claude Code + Codex 사용` 중 실제 사용할 조합을 고릅니다.
4. 설치·로그인이 확인되면 작업할 폴더를 선택해 부서를 만듭니다.

터미널에서 로그인했다면 앱에서도 해당 로그인을 사용합니다. 로그인이 만료되면 오류 팝업에서 로그인 복구를 선택하거나 멤버의 터미널에서 `로그인`을 누르세요. 로그인 후 `로그인 연결 · 요청 재시도`로 멈춘 요청을 이어갈 수 있습니다. 대화나 작업 기록은 지우지 마세요.

## 작업 진행과 승인

부장에게 목표와 완료 기준을 설명하세요. 부장이 회의를 열고 작업을 배정하며, 단계별 결과를 정리한 뒤 다음 단계로 진행합니다. `부장과 대화 · 회의 보기`와 `단계 기록`에서 내용과 진행 상태를 확인할 수 있습니다.

팀원에서 팀장으로 보낸 질문은 상사가 처리합니다. 사용자의 판단이 필요한 질문이나 실행 허가는 `내 책상`에서 확인합니다. 자동 단계 진행을 사용해도 필요한 실행 허가는 직접 확인해야 합니다.

작업 도중에도 부장에게 질문하거나 변경 지시를 보낼 수 있습니다. 실행 권한이나 로그인 문제로 중단되면 팝업에 표시된 조치를 먼저 완료하고 재시도하세요.

## 부서 전환과 오류 안내

부서 탭을 누르면 해당 부장 AI가 자동 선택되고 오른쪽 정보와 명령 대상도 함께 바뀝니다. 해당 부장이 없으면 다른 부서로 명령을 보내지 않습니다.

오류 팝업에서는 문제·영향·지금 할 일을 쉬운 문장으로 안내합니다. 연결된 AI가 있으면 별도의 임시 요청으로 설명을 보완하며, 기존 부장·팀원의 대화나 작업에 지시를 넣지 않습니다. 설명 요청에도 계정의 AI 사용량이 쓰일 수 있습니다.

AI 설명은 추정이며 실제로 문제를 해결했다는 뜻이 아닙니다. 설명을 받지 못해도 기본 안내는 바로 표시됩니다. 원문은 **오류 원문 보기**에서 펼쳐 확인할 수 있습니다. 비밀번호·인증 키 같은 정보는 AI 전달 전에 알려진 형식에 따라 가립니다. 공유 전에는 원문에 개인 정보가 없는지 직접 확인하세요.

## 저장·업데이트·복구

- 앱 설정과 조직 정보: `%LOCALAPPDATA%\pixel-office`
- 프로젝트별 AI 대화와 작업 기록: 선택한 프로젝트의 `.pixel-office` 폴더
- 문제 확인용 내부 실행 기록: `%LOCALAPPDATA%\pixel-office\daemon.log`

업데이트 전에는 앱을 정상 종료하고 위 두 데이터 폴더를 백업하세요. 새 ZIP은 **새 폴더**에 풀어서 실행합니다. 기존 ZIP 위에 덮어쓰지 마세요. 데이터 폴더는 배포 ZIP에 포함되지 않으며 새 버전에서 다시 사용합니다. 이전 버전으로 되돌릴 때는 백업한 데이터도 함께 복원해야 할 수 있습니다.

앱을 다시 열면 저장된 조직과 작업 복구를 시도합니다. 로그인 만료나 권한 차단은 먼저 해결해야 합니다. 중단된 요청의 결과가 불확실하다는 안내가 나오면 실제 파일과 터미널 결과를 확인하고 재시도하세요.

원격 연결은 선택 기능입니다. 다른 기기로 연결할 때만 별도 [원격 연결 안내](https://github.com/MaoEmong/pixel-office/blob/main/docs/%EC%9B%90%EA%B2%A9%EC%A0%91%EC%86%8D.md)를 참고하세요.

## 실행되지 않을 때

- 파일 누락: ZIP 전체를 새 폴더에 다시 풀어 주세요. 보안 프로그램에서 파일을 차단했는지도 확인하세요.
- AI 미설치·로그아웃: `환경 점검 · CLI 로그인`에서 확인하고 해당 AI를 설치하거나 로그인하세요.
- 로그인은 됐지만 Windows 실행 권한 오류가 나는 경우: 해당 멤버를 다시 시작한 뒤 `선택 멤버 검사`를 실행하세요. 계속 실패하면 [환경 문제 해결](https://github.com/MaoEmong/pixel-office/blob/main/docs/%ED%99%98%EA%B2%BD-%EB%AC%B8%EC%A0%9C%ED%95%B4%EA%B2%B0.md)을 참고하세요.
- 문제가 계속되면 오류 문구, 앱 버전, 사용한 AI 프로그램 버전과 재현 순서를 [이슈](https://github.com/MaoEmong/pixel-office/issues)에 남겨 주세요. 로그인 정보나 원본 `daemon.json`, 개인 프로젝트 내용은 공개하지 마세요.

포함한 외부 구성품의 사용 조건은 `licenses` 폴더, `data/flutter_assets/NOTICES.Z`, `dev/daemon/node_modules` 내 각 패키지의 라이선스를 확인하세요.
