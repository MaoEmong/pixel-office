# 픽셀 오피스 0.1.1 · Windows 시험판

## 달라진 점

- 부서 탭을 누르면 해당 부장 AI가 자동 선택됩니다. 오른쪽 정보와 명령 대상이 함께 바뀌며, 부장이 없으면 이전 부서로 명령을 보내지 않습니다.
- 오류 팝업에 문제, 작업에 미칠 수 있는 영향, 지금 할 일을 쉬운 문장으로 표시합니다. 오류 원문은 따로 펼쳐 볼 수 있습니다.
- 연결된 Claude Code 또는 Codex를 별도 임시 세션으로 실행해 설명을 보완합니다. 기존 부장·팀원 대화에 지시를 넣지 않으며, 파일 수정·명령 실행 도구와 사무실 연결 기능은 사용하지 않습니다.
- AI 설명이 늦거나 실패해도 기본 안내와 원문은 유지됩니다. 같은 오류의 설명을 재사용하고 동시에 하나만 요청합니다. 창을 닫은 뒤 도착한 설명은 화면에 반영하지 않습니다.
- AI에 보내는 오류에서 알려진 인증 키·비밀번호·인증 헤더·쿠키 형식을 가립니다. 원문을 공개할 때는 사용자가 개인 정보 포함 여부를 확인해야 합니다.
- 긴 원문을 펼쳐도 팝업의 닫기 버튼은 화면에 남도록 조정했습니다.
- 연결 재시도 직후 종료가 겹칠 때 생기던 중복 종료 오류를 수정했습니다.

## 설치·업데이트

Windows 10/11 x64용입니다. ZIP 전체를 새 폴더에 풀고 `pixel_office.exe`를 실행하세요. AI 명령 프로그램과 계정 로그인은 별도로 필요합니다.

0.1.0 사용자는 진행 중인 작업을 마친 뒤 앱과 내부 작업 관리 프로그램을 정상 종료하고 데이터 폴더를 백업하세요. 기존 설치 폴더를 덮어쓰지 말고 새 폴더의 0.1.1을 실행하세요. 자세한 경로와 방법은 [사용 안내](README-KO.md)를 참고하세요.

## 확인 범위

이 PC의 자동 검사와 별도 사용자·설정·포트를 사용한 배포본 검사 결과는 [검증 기록](https://github.com/MaoEmong/pixel-office/blob/main/docs/release/0.1.1/VERIFICATION.md)에 정리합니다. Claude Code와 Codex의 예시 오류 설명 응답을 각각 확인했습니다. AI 설명은 추정이며 원인을 확정하거나 문제를 직접 해결했다는 뜻이 아닙니다. 설명 요청에도 계정의 AI 사용량이 쓰일 수 있습니다.

코드 서명과 다른 PC의 실제 계정으로 처음 설치·로그인·작업 완료까지 이어가는 확인은 완료하지 않았습니다. 이번 버전도 Windows 시험판으로 배포합니다.
