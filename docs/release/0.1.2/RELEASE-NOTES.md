# 픽셀 오피스 0.1.2 · Windows 시험판

## 달라진 점

- **앱 안에서 웹페이지 확인:** 오른쪽 웹 미리보기에서 개발 중인 페이지를 열고 부서별 마지막 주소를 기억합니다. 뒤로·앞으로·새로고침, 넓게 보기와 외부 브라우저 열기를 지원합니다.
- **기존 작업과 분리:** 미리보기를 열어도 AI 작업과 명령 입력은 계속할 수 있습니다. 웹페이지에서 AI 연결·프로젝트 파일을 조작할 통로는 제공하지 않습니다. 개발 서버를 자동으로 실행하지 않습니다.
- **터미널 입력 복구:** Windows 입력 연결, 클릭 후 다시 입력, 한글 조합과 멤버 전환을 보완했습니다.
- **부장 대기 복구:** Claude의 하단 안내 문구가 달라져도 입력 가능 상태를 인식합니다. 연결 복구 후 미응답 변경 요청을 부장에게 다시 전달합니다.
- **취소한 작업 보존:** 취소한 구현을 다시 시작하지 않고 기존 회의와 취소 보고를 보존하며 변경 계획을 세우도록 했습니다.

## 설치·업데이트

Windows 10/11 x64용입니다. ZIP 전체를 **새 폴더**에 풀고 `pixel_office.exe`를 실행하세요. 원본 개발 코드와 개인 작업 기록은 포함하지 않습니다. AI 명령 프로그램·로그인은 별도로 필요합니다.

웹 미리보기에는 Microsoft Edge WebView2 Runtime이 필요하며 ZIP에 포함하지 않습니다. 없는 경우 미리보기 안의 안내를 확인하거나 외부 브라우저를 사용하세요.

기존 사용자는 진행 중인 작업을 마친 뒤 앱과 내부 작업 관리 프로그램을 정상 종료하고 데이터 폴더를 백업하세요. 기존 설치 폴더를 덮어쓰지 마세요. 자세한 방법은 [사용 안내](README-KO.md)를 참고하세요.

## 확인 범위

자동 검사와 새 사용자·설정·포트를 사용하는 Windows 배포본 검사 결과는 [검증 기록](https://github.com/MaoEmong/pixel-office/blob/main/docs/release/0.1.2/VERIFICATION.md)에 정리합니다. 검사에는 모의 AI 응답이 포함됩니다. 실제 계정의 장시간 작업 성공을 보장하는 수치는 아닙니다.

코드 서명과 다른 PC에서의 최초 설치·로그인·장시간 작업 확인은 완료하지 않은 시험판입니다. 이번 빌드 과정에서 사용 중인 앱과 AI 작업은 재시작하거나 조작하지 않았습니다.
