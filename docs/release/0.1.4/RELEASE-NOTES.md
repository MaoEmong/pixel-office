# 픽셀 오피스 0.1.4 · Windows 시험판

## 이번 버전에서 바뀐 점

- 앱 실행 파일·창·작업 표시줄에 픽셀 오피스 전용 아이콘을 적용했습니다.
- Windows 파일 속성의 제작자를 MaoEmong, 제품명을 Pixel Office로 정리했습니다.
- 빈 사무실에 AI 준비 → 부서 만들기 → 첫 지시 순서를 표시합니다.
- ‘준비 상태 확인’과 ‘처음 사용 안내’에서 설치·로그인 확인으로 이동할 수 있습니다.
- 메뉴에서 다시 여는 안내에 공식 AI 설치 링크와 복사할 수 있는 첫 지시 예시를 넣었습니다. 안내 중 연결 상태가 바뀌면 버튼 상태도 갱신됩니다.
- README와 검증 기록에서 지원 기능과 실제로 검사한 범위를 구분했습니다.

## Antigravity 지원은 계속 포함됩니다

0.1.3에 추가한 Antigravity 연결·폴더 접근 허가·사용량 표시는 0.1.4에도 포함됩니다. 이번 버전에서 해당 기능을 제거하거나 새로 추가한 것은 아닙니다.

실제 계정으로 확인한 개발 중 검사와, 로그인 없는 별도 환경에서 진행한 최종 ZIP 검사는 범위가 다릅니다. 자세한 내용은 [검증 기록](VERIFICATION.md)을 참고하세요.

## 설치·업데이트

Windows x64용 ZIP 전체를 새 폴더에 풀고 pixel_office.exe를 실행하세요. AI 프로그램 설치와 로그인은 별도로 필요합니다. 앱 실행에 필요한 Node.js와 기본 구성품은 포함되어 있습니다.

기존 사용자는 작업을 마친 뒤 앱을 정상 종료하고 앱 데이터 폴더와 프로젝트의 .pixel-office 폴더를 백업하세요. 기존 설치 폴더 위에 덮어쓰지 말고 새 폴더에서 실행하세요. 자세한 절차는 [사용 안내](README-KO.md)에 있습니다.

코드 서명이 없는 시험판입니다. 다른 PC에서의 최초 설치·로그인 검사는 아직 진행하지 않았습니다. macOS·Linux용 실행 파일은 이번 배포에 없습니다.
