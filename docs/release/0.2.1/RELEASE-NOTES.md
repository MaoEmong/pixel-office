# 픽셀 오피스 0.2.1 · Windows 시험판

## 검사와 결과 대기를 화면에서 확인

- AI 답변이 끝나도 별도 검사·명령이 남아 있으면 실행 중임을 표시합니다.
- 누가 누구의 어떤 업무 결과를 기다리는지 PC와 모바일에서 확인합니다. 실행 중 표시는 검사 성공이나 계속 진전한다는 보장은 아닙니다. 질문·허가·연결 오류 안내를 함께 확인하세요.

## 긴 대화와 작업 전달 보완

- 대화 100개 이후에도 기존 대화에서 질문과 새 지시를 이어 갑니다.
- 과거 대화는 나누어 읽고 새 메시지만 추가 저장하여 긴 대화의 조회·전달 부담을 줄였습니다. 전체 백업·첫 변환·전체 내보내기에는 기록 수에 비례하는 시간이 걸립니다.
- 답변 종료와 입력 준비 시점이 어긋나 대기 지시가 전달되지 않던 문제와, 다른 업무 때문에 완료 보고가 막히던 문제를 고쳤습니다.
- 미완료 진행 보고가 있으면 나중에 배정된 업무도 답변 종료만으로 완료 처리하지 않습니다.
- Windows 터미널의 닫힌 출력 연결에서 늦은 출력이 발생하는 오류 처리를 보완했습니다. 모든 연결 오류가 해결됐다는 뜻은 아닙니다.

## 화면과 기록 보호

- 대기 목록을 마우스로 끌어 스크롤하고 부서 목록에서 이름을 바꿀 수 있습니다.
- 실제 답변 종료 후 입력 복구를 보완했습니다. 사용자 작성 중인 글을 대신 제출하지 않습니다.
- 나중에 키 저장소에 등록한 값도 과거 대화 조회와 파생 내보내기에서 가립니다. 원본 대화·DB·기존 백업을 소급 변경하는 기능은 아닙니다. 등록된 값만 대상으로 하므로 모든 비밀값을 찾아내는 기능으로 해석하지 마세요.
- 연결 기능 선언이 다른 클라이언트의 동일 요청 재시도에서도 요청은 한 번만 실행하고, 각 연결에 맞는 응답 형식을 제공합니다.

설치·업데이트는 [사용 안내](README-KO.md), 실제 검사 범위와 제한은 [검증 기록](https://github.com/MaoEmong/pixel-office/blob/main/docs/release/0.2.1/VERIFICATION.md)을 참고하세요. 이번 파일은 Windows x64용 서명 없는 시험판입니다.
