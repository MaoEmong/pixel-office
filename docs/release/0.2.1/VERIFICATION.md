# Windows 0.2.1 배포 검증

2026-10-28 기준입니다. 같은 Windows PC에서 기존 계정과 분리한 검사와 실제 기존 작업의 교체·재개를 구분했습니다. 다른 PC의 최초 설치 결과로 표현하지 않습니다.

## 최종 소스와 화면 검사

- 서버 전체 1,530 통과·17 제외·실패 0, 형식 검사 통과.
- PC 화면 전체 981 통과·1 제외·실패 0, 분석 검사 지적 없음. 사용자 설정과 분리한 폴더를 사용했습니다.
- 실제 모바일 브라우저 검사 2개 통과. 작성 중 입력 보존, 과거 페이지와 새 변경분의 순서 복구, 대기 관계 표시를 검사했습니다.
- 배포 전 검토에서 과거 대화의 뒤늦은 키 등록 가림과 연결별 요청 재시도 응답 회귀 2개를 가짜 데이터로 재현했습니다. 수정 뒤 관련 32개가 통과했습니다. 원본 DB 행을 다시 쓰지 않는 조건과 파생 파일 교체 실패 시 이전 완전한 파일 보존도 확인했습니다.

## 최종 ZIP 검사

- Windows 앱과 서버를 별도 폴더에서 새로 빌드했습니다.
- ZIP을 다시 풀어 전체 파일 목록·SHA256, 개발 원본·소스맵·계정·프로젝트 데이터 제외를 검사했습니다.
- 실제 Windows 앱에서 별도 사용자 경로·데이터·포트로 시작·원격 화면·미설치 AI 안내·정상 종료·설정 복원·서버 자동 복구 등 10개 검사가 통과했습니다. 실제 AI를 호출하지 않는 검사입니다.
- 포장된 서버의 문서 읽기·편집·충돌/경로 보호, 시험 프로젝트 파일 저장·확인 후 복구·타임라인 보존, Windows 암호화 키 저장과 확인 없는 전체 허가 거절을 검사했습니다. 키 등록 전에 저장한 과거 대화도 등록 뒤 조회에서 가려집니다. 두 번 시작한 뒤 기록 보존을 확인했습니다.
- 구형 형식의 대화 5,000개를 강제 백업 뒤 변환하고 전체 페이지·변경분 전달·재시작 후 보존을 확인했습니다. 포장된 실제 종료 신호로 미완료 업무가 임의 완료되지 않는 것과 결과 대기 관계도 확인했습니다.
- 실행 묶음의 Windows 출력 연결 회귀 검사 4개가 통과했습니다.
- 배포 파일 1,944개(목록 파일 포함)와 공개 문서에서 검사 대상으로 둔 개인 식별 문자열은 발견되지 않았습니다. 모든 비밀값이나 개인정보가 없음을 보증하는 검사로 표현하지 않습니다.

## 기존 작업에서 적용·보존·재개

- 실제 기존 DB의 읽기 전용 복사본에서 대화 223개·업무 116개·질문/허가 이력 63개 및 나머지 기록 해시를 보존했습니다. 새 형식으로 변환하고 두 번 열어 검사했습니다.
- 사용자가 현재 검사 종료 후 후속 작업을 잠시 보류하는 방식을 승인했습니다. 실행 중인 검사는 끝까지 두고 결과 저장·환경 정리를 마친 뒤 모든 담당자의 대기, 실제 실행 없음, 열린 질문/허가 없음, 작성 중 입력 없음을 확인했습니다.
- 원본 AI 대화 파일 6개를 별도 복사·해시 검증하고, DB를 백업한 뒤 같은 데이터 폴더로 0.2.1을 적용했습니다.
- 적용 직전 기존 대화·첨부 224개, 업무 116개, 질문/허가 이력 63개, 부서·멤버·대화 ID와 완료 4개 단계 보존을 확인했습니다. 원본 대화 파일의 기존 바이트도 유지됐습니다. DB 무결성 검사 통과.
- 부장이 재개 안내를 접수하고 기존 대화에서 후속 업무를 전달했습니다. 같은 대화에서 담당자의 실제 파일 읽기·명령 실행과 진행 보고를 확인했습니다.
- 복구 중 Codex 모델 목록 확인이 잠시 대기한 뒤 자동 재연결됐습니다. 기존 대화 ID와 실행 프로세스를 확인했으며 다른 담당자의 정상 작업을 중단하지 않았습니다. 이 사례가 모든 서비스의 연결 문제 해결을 뜻하지는 않습니다.
- 기존 프로젝트 자체의 마지막 현황판 카드 검사는 실패한 상태로 기록했고, 해당 담당자가 남은 원인 조사를 이어갔습니다. 앱 적용 완료와 프로젝트 전체 완료는 구분합니다.
