## 진행 중인 작업과의 구분

선행 로컬 수정본에서는 기존 AI 대화·업무·질문·완료 단계·원본 파일 보존 후, 대기 조건 해제와 담당자의 실제 자료 조회 및 상사 보고까지 확인했습니다. 이 로컬 확인과 최종 ZIP 검사는 구분합니다. 배포 전 추가한 자동 완료 보호는 위의 격리 검사로 확인한 배포 파일의 수정이며, 현재 실행 중인 사용자 앱에 이미 적용됐다는 뜻은 아닙니다.

**이번 배포를 위해 현재 MES 앱·서버·실행 중인 검사는 종료하거나 재시작하지 않습니다.** MES 전체 완료도 별개입니다. 최종 ZIP은 위 커밋으로 만들었고 이후 이 검증 문서와 공개 안내 정리는 실행 파일을 변경하지 않습니다. 업로드 후 공개 파일을 인증 없이 다시 내려받아 같은 해시인지 별도로 확인합니다.

## 확인하지 않은 범위

Windows x64 시험판입니다. 코드 서명, 다른 PC의 최초 설치·AI 로그인, macOS·Linux 배포는 확인하지 않았습니다. 저장 형식은 기존 0.2.1~0.2.4와 같은 8입니다. 모든 연결 오류·AI 버전·외부 명령의 성공을 보장하지 않습니다. 조회 범위 밖의 접수나 이동한 기록 파일 등으로 확인할 수 없으면 접수 미확인 상태를 유지합니다. 저장 전 연결에 도달하지 않은 직접 입력까지 복구한다고 보장하지 않습니다.
