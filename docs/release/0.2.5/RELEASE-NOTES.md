# 픽셀 오피스 0.2.5

Windows x64 시험판입니다. 0.2.4 이후의 답변 누락·Codex 입력·결과 대기 표시와 재개 수정을 포함합니다.

## 바뀐 점

- 부장의 최종 답변을 마지막 내부 메시지나 재연결 상태와 관계없이 대화 기록에 남깁니다.
- 상사의 일반 메시지에 대한 담당자의 최종 답변을 상사에게 전달하고, 접수 전 연결이 끊겨도 보존합니다. 단순 답변을 업무 완료로 처리하지 않습니다.
- Windows Codex의 입력 준비 확인과 한글·기호 입력을 보완하고, 접수 신호가 빠진 경우 같은 대화의 기록으로 접수 여부를 확인합니다.
- 기다리는 담당자와 필요한 결과, 결과 도착 후 할 일을 PC·모바일에 표시합니다. 모든 결과가 확인되면 기존 대화에 재개 안내를 전달합니다.
- 일부 결과만 도착한 경우, 중복 결과, 재연결, 단계 변경이 겹쳐도 대기 조건을 구분합니다. 작성 중인 입력·질문·허가·사용 한도·실행 중 명령은 그대로 존중합니다.
- 결과 대기로 답변을 마친 업무가 자동 완료되지 않도록 보호하고, 재개·취소·재연결 뒤에도 명시적인 완료 보고를 기다립니다. 새 질문 표시는 유지합니다.

## 결과를 기다리는 동안

담당자를 선택하면 누구의 어떤 결과를 기다리는지와 결과 도착 후 할 일을 확인합니다. 결과 제공자가 실제 결과를 확인해 알리면, 필요한 결과가 모두 모였을 때 원래 담당자에게 재개 안내가 전달됩니다. 결과 도착·지시 접수·실제 후속 실행은 구분합니다. 등록되지 않은 대기 사유를 과거 답변만으로 추측하지 않습니다.

재개 안내는 검사 성공이나 업무 완료, 사용자 허가를 뜻하지 않습니다. 작성 중인 입력이나 열린 질문·허가가 있으면 기존 입력 전달 규칙에 따라 기다립니다. 오래 걸리는 검사를 자동 취소하거나 다시 실행하지 않습니다. 저장 전 입력과 모든 연결 오류까지 복구한다고 보장하지 않습니다.

## 업데이트

진행 중인 명령·검사를 마치고 작성 중인 글을 저장한 뒤 앱을 정상 종료하세요. 앱 데이터와 프로젝트의 `.pixel-office`를 함께 백업하고 새 ZIP 전체를 **새 폴더**에 풉니다. 저장 형식은 기존 0.2.1~0.2.4와 같은 8입니다. 재연결 뒤 기존 대화와 미완료 업무를 확인하세요. [설치·업데이트 안내](README-KO.md)

이번 배포를 위해 진행 중인 사용자 MES 앱을 다시 시작하지 않습니다. [검증 범위](https://github.com/MaoEmong/pixel-office/blob/main/docs/release/0.2.5/VERIFICATION.md)
