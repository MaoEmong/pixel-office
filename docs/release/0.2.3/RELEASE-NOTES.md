# 픽셀 오피스 0.2.3

Windows x64 시험판입니다. 0.2.2 이후의 서버 연결 준비와 지시 접수 상태 수정을 포함합니다.

## 연결과 재시작

- 서버가 실제 접속을 받을 준비가 된 뒤 접속 정보를 공개합니다. 앱과 명령 도구는 준비 전 포트 0과 잘못된 포트로 연결하지 않습니다.
- Windows에서 앱이 접속 정보 파일을 잠깐 읽는 동안 파일 교체가 거부되면 제한 시간 안에서 기다립니다. 지속되는 오류는 숨기지 않으며 이전 완성 파일을 보존합니다.
- 시작 중 접속 정보 공개가 실패하면 열어 둔 연결과 이미 복구한 AI를 저장 종료합니다. 기존 대화와 미완료 업무는 다음 복구를 위해 보존합니다.

## 지시 접수와 작업 상태

- 한도 복구 시 긴 업무·대화 전체를 중복 전달하는 대신 짧고 완전한 요약을 보냅니다. 업무·질문·대화 원문은 보존합니다.
- 지시가 실제로 접수됐는지 확인되지 않거나 입력 준비가 오래 지연되면 **지시 접수 확인 필요**를 표시합니다. 상사에게도 어느 담당자의 지시 전달이 멈췄는지 보여줍니다.
- 부장·팀장의 업무 상태 조회에도 실제 활동과 지시 접수 상태를 포함합니다. **미완료 업무 있음**은 완료 보고가 남았다는 뜻이며, 그 자체로 검사나 명령이 실행 중이라는 뜻은 아닙니다.
- 상태 조회와 표시는 지시 재전송·작업 재시작·허가 승인·업무 완료 처리를 대신하지 않습니다.
- 패널을 닫은 뒤 화면 설정 읽기가 늦게 끝나도 닫힌 화면을 갱신하지 않습니다.

## 업데이트

진행 중인 명령과 검사를 끝내고 작성 중인 내용을 저장한 뒤 앱을 정상 종료하세요. 앱 데이터 폴더와 프로젝트의 `.pixel-office`를 백업하고 새 ZIP 전체를 **별도 폴더**에 풉니다. 0.2.1·0.2.2와 같은 저장 형식 8을 사용합니다. [사용·업데이트 안내](README-KO.md)

이번 수정이 모든 연결 문제나 장시간 작업의 성공을 보장하지는 않습니다. AI 프로그램 설치와 계정 로그인은 별도입니다. [검증 범위](https://github.com/MaoEmong/pixel-office/blob/main/docs/release/0.2.3/VERIFICATION.md)
