- 이번 배포는 앱 화면 소스 변경 없이 버전만 올렸고 Windows 앱을 새로 빌드했습니다.

## 실제 Windows 앱과 AI

기존 PC의 설치·로그인된 Codex 0.163.0 / gpt-6.1-sol을 사용했습니다. 개인 프로젝트 대신 새 시험 폴더와 새 앱 데이터를 사용했습니다.

1. ZIP 전체를 풀고 앱 실행 → 준비 상태에서 Codex 설치·로그인 확인 → Codex만 선택해 부서 생성.
2. README.md와 orders.csv를 읽고 합계를 질문. 실제 파일 읽기 후 품목당 6,000, 전체 18,000 답변을 확인했습니다.
3. 답변 완료 후 앱을 정상 종료. 업로드한 ZIP을 다시 내려받아 새 폴더에 풀고 같은 시험 데이터로 실행했습니다.
4. 기존 부서·멤버·작업 흐름·AI 대화 ID와 두 메시지가 같았습니다. 추가 질문에도 품목별 금액과 전체 18,000을 답했습니다.
5. 화면에 대화 4개·회의 0·작업 계획 0·단계 기록 0과 답변 완료가 표시됐습니다. 저장된 업무·열린 질문/허가도 0이고 시험 파일은 바뀌지 않았습니다.

앞선 후보 ZIP에서는 세 질문과 정상 재실행을 별도로 시험했습니다. 최종 0.2.6 ZIP에서 수행한 실제 AI 질문은 위 두 번입니다.

## 기존 자료 보존

기존 MES 앱 데이터 5개와 원본 대화 파일 35개의 검증값이 배포 작업 전후 모두 같습니다. 기존 DB를 열거나 수정하지 않았고, MES 작업을 재개·중단·취소하거나 담당자에게 지시하지 않았습니다. 빌드·캐시·임시·시험 자료는 모두 E드라이브에 저장했습니다.
