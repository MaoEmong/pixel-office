# 픽셀 오피스 0.2.6

Windows x64 시험판입니다. 단순 질문의 답변 뒤 회의·미완료 업무가 남던 문제와 연결 복구·사용 한도 안내를 보완했습니다.

## 바뀐 점

- 설명·조회·계산처럼 답변만 필요한 질문에는 부장이 직접 답하고, 회의나 미완료 업무를 새로 만들지 않도록 안내를 고쳤습니다. 연결 복구 뒤에도 같은 기준을 사용합니다.
- 확인된 Windows AI 프로그램 비정상 종료 뒤 업무와 하위 담당자를 함께 종료하던 처리를 보완했습니다. 원래 대화와 미완료 업무를 유지하고 제한된 횟수로 해당 담당자의 재연결을 시도합니다.
- 최신 사용량으로 회복을 확인한 과거 소진 기록은 다시 차단에 사용하지 않습니다. 이미 유효하지 않은 갱신 날짜도 숨깁니다. 실제 소진·미확인 상태와 사용자의 재개 선택은 유지합니다.

단순 질문과 실제 팀 작업을 구분하도록 AI에 전달하는 안내를 수정했습니다. 기존 미완료 업무를 임의로 완료 처리하거나 삭제하는 변경은 아닙니다. 실제 팀 작업의 완료 확인도 유지합니다.

## 업데이트

진행 중인 명령·검사를 마치고 작성 중인 글을 저장한 뒤 앱을 정상 종료하세요. 앱 데이터와 프로젝트의 .pixel-office를 함께 백업하고, ZIP 전체를 **새 폴더**에 풉니다. 저장 형식은 0.2.5와 같은 8입니다. 재연결 뒤 기존 대화와 업무를 확인하세요. [설치·업데이트 안내](README-KO.md)

이번 배포 과정에서 기존 MES 데이터나 원본 대화는 변경하지 않습니다. 배포와 실행 중인 앱의 교체는 별개입니다.

## 확인 범위와 제한

별도 시험 자료로 실제 Codex의 파일 읽기·계산 답변, 연속 질문과 정상 종료·재실행 뒤 같은 대화의 후속 답변을 확인했습니다. 세 AI의 공통 안내와 실제 팀 작업의 완료 보호는 자동 검사로 확인했습니다. 모든 AI의 실제 실행을 각각 시험한 것은 아닙니다.

이 PC에 이미 설치·로그인한 AI를 사용했습니다. 다른 PC의 최초 설치·로그인과 Windows 코드 서명은 아직 검증하지 않았습니다. 재실행 중 Codex 모델 목록 연결 안내가 한 번 나타났으나 재연결 후 답변은 이어졌습니다. 모든 연결 오류나 AI 프로그램 자체의 비정상 종료를 해결한 배포는 아닙니다.
