# 픽셀 오피스 0.2.4

Windows x64 시험판입니다. 0.2.3 이후의 지시 전달·연결·한도 확인 복구 수정을 포함합니다.

## 바뀐 점

- 입력칸 준비를 기다리는 지시·보고를 먼저 저장해, 앱과 담당자 재연결 뒤에도 누락되지 않도록 보강했습니다.
- 실제 접수가 불확실할 때 같은 지시를 곧바로 재전송하지 않고, 해당 대화의 접수 기록을 제한된 범위에서 확인합니다.
- 입력 연결이 닫히거나 화면 새로 그리기가 실패해도 대기 지시를 보존하며, 작성 중인 사용자 입력을 덮어쓰지 않습니다.
- 실행 중 명령과 결과 대기 상태를 함께 확인하고, 종료 신호가 빠졌을 때 성공으로 표시하지 않습니다.
- Claude 입력줄 일부가 가려지는 경우와 별도 실행·감시 표시를 보완했습니다.
- 시작 중 폴더 확인, 한도 갱신 뒤 오래된 차단 정보, 사용량 확인 명령의 접수 누락과 재연결을 보완했습니다.

## 복구의 범위

지시의 접수 기록을 확인할 수 있으면 중복 전송 없이 다음 작업을 이어갑니다. 확인할 수 없는 지시는 접수 확인이 필요한 상태로 남깁니다. 실제 실행 중인 검사·빌드를 시간이 지났다는 이유로 자동 취소하거나 다시 실행하지 않습니다. 로그인·사용 한도·허가 대기는 별도 확인이 필요합니다. 저장되기 전에 연결에 도달하지 않은 직접 입력까지 복원한다고 보장하지 않습니다.

## 업데이트

진행 중인 명령·검사를 끝내고 작성 중인 글을 저장한 뒤 앱을 정상 종료하세요. 앱 데이터와 프로젝트의 `.pixel-office`를 함께 백업하고 새 ZIP 전체를 **새 폴더**에 풉니다. 저장 형식은 기존 0.2.1~0.2.3과 같은 8입니다. 재연결 뒤 기존 대화와 미완료 업무를 확인하고 작업을 이어가세요. [사용·업데이트 안내](README-KO.md)

이번 배포를 위해 진행 중인 사용자 MES 앱을 다시 시작하지 않습니다. 모든 연결 오류나 외부 명령의 성공을 보장하는 수정은 아닙니다. [검증 범위](https://github.com/MaoEmong/pixel-office/blob/main/docs/release/0.2.4/VERIFICATION.md)
