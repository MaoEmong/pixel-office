# 픽셀 오피스 0.1.3 · Windows 시험판

## 달라진 점

- **Antigravity 연결:** Google 계정으로 로그인한 Antigravity CLI를 부장·팀장·팀원으로 선택할 수 있습니다. 처음 사용하는 폴더는 앱에서 접근을 허가하거나 거부합니다.
- **사용량 표시:** AI 사용량 버튼에 마우스를 올리면 요약, 누르면 상세 한도를 봅니다. Antigravity는 그룹별 주간·5시간 한도와 갱신 시간을 표시합니다. Antigravity 안의 Claude·GPT 한도는 별도 Claude Code·Codex 구독 한도와 다릅니다.
- **AI 선택:** 조합 목록 대신 사용할 AI를 각각 체크합니다. 부장과 같은 AI만 쓰는 기본 설정도 유지합니다.
- **읽기 쉬운 승인:** 하려는 작업과 파일·설정에 미치는 영향을 쉬운 말로 먼저 설명하고, 삭제·덮어쓰기·외부 전송 주의사항과 실제 명령도 함께 보여줍니다.
- **입력 대기 보완:** Claude의 바뀐 대기 화면을 인식하며, 전달이 오래 막히거나 Enter 이후 접수가 확인되지 않으면 기록과 알림을 남깁니다.
- **모바일 보완:** 부장 입력칸 고정, 접을 수 있는 대화·회의·작업 영역, AI별 상세 탭과 사용자에게 필요한 요청만 모은 승인함을 제공합니다.




## 설치·업데이트

Windows 10/11 x64용입니다. ZIP 전체를 새 폴더에 풀고 pixel_office.exe를 실행하세요. AI 명령 프로그램과 로그인은 별도로 필요합니다. 웹 미리보기는 별도 Microsoft Edge WebView2 Runtime이 필요합니다.

기존 작업을 마친 뒤 앱과 내부 작업 관리 프로그램을 정상 종료하고 데이터 폴더를 백업하세요. 새 설치 폴더를 사용하며 기존 설치 폴더를 덮어쓰지 마세요. 이번 버전은 Antigravity를 위한 데이터 구조를 추가하므로 이전 버전으로 돌아갈 때는 업데이트 전 백업을 별도로 사용하세요. [사용 안내](README-KO.md)를 참고하세요.

## 확인 범위

[검증 기록](VERIFICATION.md)에 자동 검사와 별도 사용자·포트를 사용한 배포본 검사 결과를 기록합니다. Windows Antigravity CLI 1.4.6과 Google AI Pro 계정에서 실제 응답·파일 승인/거부·팀 도구·대화 복구·사용량 조회를 확인한 이력이 있습니다. 장시간 작업 성공이나 다른 PC의 최초 설치를 보장하지 않습니다.

코드 서명이 없는 시험판입니다. 배포 ZIP에는 원본 TypeScript·Dart, 소스맵, 계정과 개인 프로젝트 기록을 넣지 않습니다. 실행에 필요한 코드와 외부 구성품은 포함됩니다.
