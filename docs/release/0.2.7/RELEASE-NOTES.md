# 픽셀 오피스 0.2.7

Windows 10·11 x64 시험판입니다. 사무실과 캐릭터를 새롭게 꾸미고, 필요한 작업 창을 골라 여는 화면으로 바꿨습니다.

### 추가

- 사무실을 바탕으로 대화·회의·업무 결과·진행 상황·직원 상세 창을 각각 열고, 위치와 크기를 조절할 수 있습니다. 왼쪽 부서 목록은 접고 펼칠 수 있습니다.
- 파일·문서와 웹 미리보기를 하나의 메뉴에서 열며, 사무실 위의 오른쪽 영역이나 분리한 미리보기 창에서 확인할 수 있습니다.
- 부장·팀장·팀원의 새 캐릭터와 사무실 그림을 적용했습니다. 부장은 위쪽, 팀원은 팀별로 모여 앉고, AI 이름과 색상을 좌석에 표시합니다. 질문·허가 대기 때 상사에게 이동하며 사용자 확인이 필요하면 알림에서 상세 내용을 엽니다.
- 사무실 위 게시판을 눌러 부서별 메모를 작성하고 저장할 수 있습니다.

### 개선·수정

- 창의 접기 버튼과 사무실 버튼으로 숨긴 창을 하단 복원 버튼에서 다시 열 수 있습니다. 닫기 버튼과 접기 버튼의 동작을 구분하고 대화 초안과 열어 둔 미리보기 상태를 유지합니다.
- 하단 메뉴를 다시 누르면 열린 창을 닫습니다. 파일·미리보기 영역이 사무실을 옆으로 밀던 배치를 고쳤습니다.
- 상단 안내를 줄이고 대화·회의·업무·직원 상세 창의 내용 영역을 넓혔습니다. 사용자 질문과 허가 요청은 내용을 열어 읽고 답할 수 있습니다.
- 처음 사용 안내·설정·AI 사용량 창과 사용량 미리보기의 글자 대비, 메뉴·복원 버튼의 가독성을 보완했습니다.
- 상단 인원 수를 사무실 인원과 퇴근 인원으로 나누어 표시합니다.
- 단계 완료 알림에서 기록을 별도 창으로 열어 대화 화면으로 돌아갈 수 있게 했습니다. 숨긴 직원 상세나 다른 팝업 뒤에서 승인 단축키가 처리되지 않도록 보완했습니다.

## 업데이트

진행 중인 검사·명령을 마치고 작성 중인 내용을 저장한 뒤 앱을 정상 종료하세요. 앱 데이터 폴더와 프로젝트의 .pixel-office를 함께 백업하고 ZIP 전체를 새 폴더에 풀어 실행하세요. 저장 형식은 0.2.6과 같은 8입니다. 기존 대화와 업무를 확인한 뒤 이어서 진행하세요.

## 확인 범위

창 접기·복원, 여러 창 전환, 대화 초안과 미리보기 입력 보존, 질문·허가 상세 연결, 다양한 창 크기의 배치를 자동 검사합니다. 새 ZIP을 풀어 별도 시험 자료로 시작·저장·정상 종료·재실행과 기록 보존도 확인합니다. 자세한 결과는 같은 폴더의 VERIFICATION.md에 기록합니다.

Windows 코드 서명은 아직 제공하지 않습니다. 사용할 AI의 설치·로그인은 별도로 필요합니다. 이번 변경은 Windows 화면 중심이며 다른 PC의 첫 설치와 모든 AI 서비스의 실제 실행을 새로 검증한 것은 아닙니다.
