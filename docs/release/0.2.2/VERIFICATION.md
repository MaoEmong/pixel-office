# Windows 0.2.2 배포 검증

2026-10-28 기준입니다. 같은 Windows PC에서 기존 계정·작업과 분리한 환경으로 검사했습니다. 이번 배포 준비를 위해 진행 중인 사용자 작업을 종료하거나 새 ZIP으로 교체하지 않았습니다.

## 수정과 소스 검사

- Claude의 갱신 직후 0% 읽기, 기존 AI 구성 재개, 여러 AI의 한도 소진·부분 회복, 기존 Codex의 실행 준비, 선택 목록 가독성을 수정했습니다.
- 서버 전체 1,565 통과·17 제외·실패 0, 형식 검사 통과.
- PC 화면 전체 989 통과·1 제외·실패 0, 분석 검사 지적 없음. 사용자 설정과 분리한 폴더를 사용했습니다.
- 세 AI 각각의 단기·주간 한도, 두 AI의 모든 조합과 감지 순서, 세 AI의 모든 감지 순서, 부분 회복과 전체 회복을 제어한 시험 환경에서 확인했습니다. 실제 계정의 한도를 일부러 소진하지 않았습니다.
- 재개 중 중복 요청·준비 실패·사용량 변경과 기존 AI·대화 보존을 확인했습니다. 실제 앱 테마로 목록을 펼쳐 명암·체크·선택 문구와 좁은 창을 검사했습니다. 사용자가 로컬 수정본의 화면 확인을 완료했습니다.
- 배포 검토에서 재개 준비 중 앱을 종료하면 새 AI 실행이 남는 문제를 재현했습니다. 준비 완료 후 종료 여부·담당자 상태·AI 설정을 다시 확인하도록 수정하고 관련 49개 검사를 통과했습니다. 종료 후 새 실행이 없고 대화·업무·단계·중지 기록이 보존됨을 확인했습니다.

## 최종 ZIP 검사

- Windows 앱과 서버를 별도 폴더에서 새로 빌드하고, ZIP을 다시 풀어 전체 파일 목록·SHA256과 원본 코드·소스맵·사용자 데이터 제외를 검사했습니다.
- 실제 Windows 앱의 별도 사용자 경로·데이터·포트로 시작, 원격 화면, 미설치 AI 안내, 정상 종료, 설정 복원, 서버 자동 복구 등 10개 검사가 통과했습니다. 실제 AI를 호출하지 않는 검사입니다.
- 구형 형식의 대화 5,000개를 강제 백업 뒤 변환하고 전체 페이지·변경분 전달·두 번 시작 후 보존을 확인했습니다.
- 포장된 서버의 실제 답변 종료 신호로 미완료 업무가 임의 완료되지 않고, 결과 대기 관계·추가 배정·기존 업무가 재시작 후 유지되는지 확인했습니다.
- 포장된 서버의 문서 읽기·편집·충돌/경로 보호, 파일 저장·확인 후 복구·타임라인 보존, Windows 암호화 키 저장과 확인 없는 전체 허가 거절을 검사했습니다. 키 등록 전 저장한 대화도 등록 뒤 조회에서 가려지며, 두 번 시작한 뒤 기록이 보존됐습니다.
- 기능 보조 검사 첫 시도는 서버가 접수를 시작하기 전에 연결해 거절됐습니다. 검사 도구가 준비 완료를 확인하도록 보완한 뒤 새 시험 폴더에서 통과했습니다. 제품 코드를 바꿔 오류를 감추지 않았습니다.
- Windows 출력 연결 회귀 검사 4개 통과. 배포 파일 1,944개(목록 파일 포함)와 공개 문서에서 검사 대상으로 둔 개인 식별 문자열은 발견되지 않았습니다. 모든 비밀값·개인정보의 부재를 보증하는 검사는 아닙니다.
