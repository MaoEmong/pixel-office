# 픽셀 오피스 0.2.2

Windows x64 시험판입니다. 0.2.1 이후의 한도 복구와 AI 선택 화면 수정을 포함합니다.

## 한도 갱신과 기존 작업 재개

- Claude가 갱신 직후 ‘0% 사용’만 표시하고 다음 갱신 시각을 생략해도 새 값을 읽습니다. 예전 100%가 남아서 재개를 막던 경로를 고쳤습니다.
- **다시 확인·기존 AI 재개**는 사용량을 새로 조회한 뒤 기존 구성의 AI가 모두 사용 가능하면 같은 AI·대화로 작업을 재개합니다. 안내 창을 여는 것만으로는 작업을 시작하지 않습니다.
- Claude Code·Codex·Antigravity 중 둘 이상이 소진된 경우도 각각 확인합니다. 일부만 회복됐으면 아직 확인이 필요한 AI 이름을 표시하고 중지를 유지합니다.
- **원래 AI로 계속**을 선택해도 다른 소진된 AI의 담당자를 바꾸지 않습니다. 다른 AI로 교체하려면 별도로 선택하고 **교체하고 계속**을 눌러야 합니다.
- 기존 구성에 포함된 모든 AI의 실행 준비와 구독 로그인을 확인한 후 재개합니다. 서버 재시작 뒤 기존 Codex 담당자의 모델 목록 준비가 빠지던 경로를 고쳤습니다.
- 재개 준비 중 앱을 종료하면 새 AI 실행을 만들지 않고 중지 기록을 보존합니다.

## AI 선택 목록

- 선택 배경을 어둡게 하고 밝은 글자를 유지합니다.
- 현재 선택한 항목에는 체크와 **선택됨**을 함께 표시합니다.
- 닫힌 선택 칸에는 테두리·채움·화살표를 표시합니다. 목록에서 AI를 고르는 것만으로는 작업을 시작하지 않습니다.

## 업데이트

진행 중인 명령과 검사를 끝내고 작성 중인 내용을 저장한 뒤 앱을 정상 종료하세요. 앱 데이터 폴더와 프로젝트의 `.pixel-office`를 백업하고 새 ZIP 전체를 **별도 폴더**에 풉니다. 0.2.1과 같은 저장 형식을 사용하며, 구형 형식의 기록을 열 때는 변환 전 백업합니다. [사용·업데이트 안내](README-KO.md)

AI 프로그램 설치와 계정 로그인은 별도입니다. 한도·연결·실행 준비를 확인할 수 없으면 중지를 유지하며, 계정 변경이나 실행 허가를 대신 결정하지 않습니다. [검증 범위](VERIFICATION.md)
