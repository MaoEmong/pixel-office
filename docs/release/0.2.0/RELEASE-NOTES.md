# 픽셀 오피스 0.2.0 · Windows 시험판

## 작업과 결과를 한곳에서 확인

- **진행·기록**에서 사용자 요청별로 AI의 작업, 질문·허가, 완료 보고와 파일 저장 지점을 확인합니다.
- 완료 결과 카드에서 보고 내용, 저장 지점 사이에 바뀐 파일과 보고된 검사 결과를 봅니다. 실제로 확인하지 못한 검사를 통과했다고 표시하지 않습니다.
- 프로젝트 파일을 별도의 로컬 기록에 저장하고, 변경 내용을 확인한 뒤 선택한 시점의 파일로 되돌립니다. Git 설치가 필요합니다. 외부 서비스의 데이터나 대화까지 되돌리는 기능은 아닙니다.

## 부서와 문서를 쉽게 찾기

- 왼쪽 부서 목록에서 작업 프로젝트를 선택합니다.
- 오른쪽 **파일·문서**에서 폴더를 살펴보고 UTF-8 Markdown·텍스트 문서를 읽거나 편집합니다. 문서는 2MB까지 지원합니다.
- 파일 목록으로 돌아가기, 문서 넓게 보기와 저장 충돌 안내를 제공합니다. 저장하지 않은 글은 앱을 완전히 닫기 전에 저장해야 합니다.

## 작업이 막혔을 때 확인과 복구

- AI 사용 한도 소진이 확인되면 해당 부서를 멈추고 안내합니다. 허용된 다른 구독 AI의 연결과 잔여량이 확인되면 교체 여부를 묻습니다. 확인 없이 기존 AI를 바꾸지 않습니다.
- 하위 AI를 새로 만들 때도 소진된 AI를 피하고, 확인된 후보가 없으면 이유를 안내합니다.
- 멈춘 AI는 사용자 확인 후 **강제 퇴근**시킬 수 있습니다. 부장에게도 하위 AI의 강제 퇴근을 지시할 수 있습니다. 이미 변경된 파일은 남으며 후임 구성은 별도입니다.
- Docker 실행 대기 카드에서 Docker Desktop 실행 요청, 준비 상태 확인과 작업 재개를 할 수 있습니다. 설치·재설치나 PC 설정 변경까지 대신 처리하지는 않습니다.

## 키 저장과 허가 방식

- Windows 계정에 연결해 암호화하는 프로젝트별 키 저장소를 제공합니다. 저장된 값을 AI에 전달하면 해당 AI 서비스와 CLI 기록에 포함될 수 있습니다.
- **모든 권한 허용**은 경고 내용을 읽고 확인한 경우에만 켤 수 있습니다. 삭제·설치·외부 전송도 자동 허가되므로 기본 허가 방식으로 시작하세요.

## 입력과 안내 보완

- 중간 진행 보고와 답변이 필요한 질문을 구분했습니다.
- 긴 입력의 제출 재시도, 줄바꿈이 바뀐 입력의 접수 확인과 질문 복구를 보완했습니다.
- 해결된 대기 알림이 하단에 남는 문제, Antigravity 연결 표시와 사용량 이름 정렬을 수정했습니다.
- 한도 중지 기록의 등록된 키를 가리고, 이미 중지된 AI의 퇴근 조작으로 재개가 막히지 않도록 했습니다.
- 사무실의 결과 대기 화살표를 제거했습니다.

설치·업데이트 방법은 [사용 안내](README-KO.md), 실제 검사 범위와 미확인 항목은 [검증 기록](https://github.com/MaoEmong/pixel-office/blob/main/docs/release/0.2.0/VERIFICATION.md)을 참고하세요. 이번 파일은 Windows x64용 서명 없는 시험판이며 macOS·Linux용 배포 파일은 제공하지 않습니다.
