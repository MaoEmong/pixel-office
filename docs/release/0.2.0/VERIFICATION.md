# Windows 0.2.0 배포 검증

2026-10-27 기준입니다. 이 문서는 기능 포함 여부와 실제 확인한 범위를 구분합니다. 다른 PC에서 처음 설치한 결과로 표현하지 않습니다.

## 배포에 포함하는 기능

- Claude Code·Codex·Antigravity 연결과 사용량 표시.
- 앱 아이콘·제작자 정보·처음 사용 안내.
- 왼쪽 부서 목록, 프로젝트 문서 읽기·편집과 저장 충돌 안내.
- 요청별 타임라인, 완료 결과 카드, 로컬 파일 저장·되돌리기.
- Windows 키 저장소와 확인 후 켜는 모든 권한 허용 설정.
- AI 강제 퇴근, 사용 한도 소진 안내·확인 후 교체와 하위 AI 생성 시 잔여량 고려.
- Docker 실행 대기 안내·준비 상태 확인·작업 재개.
- 진행 보고·질문 구분, 입력 접수와 대기 알림 보완.

## 검사 결과

- 서버 형식 검사 통과. 전체 1,513건 중 1,497건 성공, 16건 건너뜀, 실패 없음.
- 앱 분석 검사 지적 없음. 앱 검사 971건 성공, 1건 건너뜀, 실패 없음. 사용자 설정과 분리한 검사 폴더를 사용했습니다.
- Windows 앱 빌드 성공. 서버 수정 후에는 화면 입력 파일이 동일함을 확인한 검증본을 유지하고, 수정 서버로 새 ZIP을 구성했습니다.
- 최종 ZIP을 새 경로에 풀고 파일 목록·SHA256·원본 개발 코드와 인증 파일 제외, 포함된 Node.js·터미널·이미지 처리·연결 신호 프로그램 실행을 확인했습니다.
- 별도 사용자 경로·데이터·포트에서 앱 실행, 원격 화면 제공, 세 AI 모두 미설치 안내, 오류 설명의 기본 안내, 정상 종료, 재실행 후 설정 복원과 서버 자동 복구 등 10개 항목을 통과했습니다.
- 최종 ZIP의 서버와 연결해 문서 목록·읽기·저장, 오래된 내용으로 덮어쓰기 거절과 폴더 밖 접근 거절을 확인했습니다.
- 시험 프로젝트의 파일 저장·복구 목록 확인·확인 없이 복구 거절·실제 파일 복구와 타임라인 유지를 확인했습니다.
- Windows 계정 암호화 키 저장·조회와 확인 없는 모든 권한 허용 거절을 확인했습니다. 서버를 다시 실행한 뒤 문서·타임라인·키가 유지되는 것도 확인했습니다.
- 1,944개 배포 파일에서 검사 대상으로 둔 개인 이메일·실명 문자열이 발견되지 않았습니다. 실행 파일의 제품명 Pixel Office, 제작자 MaoEmong, 버전 0.2.0+1도 확인했습니다.

건너뛴 검사는 별도 환경·계정이 필요한 항목입니다. 위 포장 검사는 실제 AI 로그인이나 모델 작업을 사용하지 않았습니다. 모든 비밀값이나 개인정보가 없음을 보증하는 검사로 표현하지 않습니다.

## 개발 중 실제 계정 검사와 이번 ZIP 검사

개발 중 같은 Windows PC의 기존 프로젝트에서 Claude·Codex의 대화·업무·단계 보존, 질문 전달과 회의 진행, 서버·앱 재시작 후 작업 재개를 확인했습니다. Antigravity도 개발 중 실제 Google 구독 계정으로 응답·파일 승인·팀 도구·대화 복구·사용량 조회를 확인한 이력이 있습니다.

이 이력은 기능이 들어 있다는 근거이며, 새 사용자의 최초 로그인이나 이번 최종 ZIP에서 모든 AI로 장시간 작업했다는 뜻은 아닙니다. 최종 ZIP 검사는 별도 데이터 폴더·포트·사용자 경로로 기존 작업과 분리해 진행합니다.

## 확인하지 않은 범위

- 다른 PC의 최초 설치·AI 로그인.
- 이번 ZIP에서 실제 AI 계정으로 수행하는 모든 기능과 장시간 작업.
- Windows 코드 서명. 현재 서명 없는 시험판입니다.
- macOS·Linux 배포 파일과 해당 운영체제의 이번 버전 실행. 이번 파일은 Windows x64용입니다.
