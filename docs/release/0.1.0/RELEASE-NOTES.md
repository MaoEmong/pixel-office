# 픽셀 오피스 0.1.0 시험판

Claude Code와 Codex의 실제 작업 세션을 픽셀 사무실에서 관리하는 Windows 앱입니다.

- 부서·부장·팀장·팀원 구성과 AI별 사용 설정
- 대화·회의·작업 계획을 나눠 보여 주는 화면과 실시간 갱신
- 작업 상태, 질문 대상, 사용자 승인 필요 여부 구분
- 로그인·설치·Windows 실행 권한 문제 사전 확인과 오류 팝업
- 로그인 갱신 후 요청 재시도와 재시작 후 질문·답변 전달 복구
- 부장 판단에 따른 다음 단계 진행과 단계별 결과 기록
- 실행 파일, 내부 프로그램, Node.js와 기본 DLL을 포함한 Windows 64비트 ZIP
- 내부 코드를 배포용으로 변환하고 원본 개발 파일·테스트·개발 도구·원본 복원 파일 제외

별도의 AI 프로그램 설치와 사용 가능한 계정·로그인이 필요합니다. AI 프로그램 업데이트나 계정·네트워크 상태에 따라 추가 조치가 필요할 수 있습니다. Windows 실행 권한을 앱이 임의로 해제하지는 않습니다.

다른 PC에서 실제 계정으로 처음 로그인하고 긴 작업을 끝까지 수행하는 확인은 공개 전 별도로 필요합니다. 이 시험판은 모든 PC와 장시간 작업의 안정성을 보장하는 정식판이 아닙니다.
