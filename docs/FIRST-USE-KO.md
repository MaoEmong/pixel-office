# 픽셀 오피스 처음 사용하기

픽셀 오피스는 여러 AI가 맡은 일과 대화, 사용자의 허가를 기다리는 요청을 사무실 화면에서 확인하는 윈도우 앱입니다. **처음에는 AI 하나와 작은 작업으로 시작하세요.**

## 1. 사용할 AI 하나 준비하기

아래 프로그램 중 사용할 것만 공식 안내에 따라 설치하고 로그인하세요.

- [Claude Code 설치 안내](https://code.claude.com/docs/en/setup)
- [Codex 설치 안내](https://developers.openai.com/codex/cli/)
- [Antigravity 설치 안내](https://antigravity.google/docs/cli/)

AI 계정과 이용 가능한 요금제·사용량은 각 서비스의 조건을 따릅니다. 픽셀 오피스가 AI 이용권을 제공하지는 않습니다.

픽셀 오피스 첫 화면의 **준비 상태 확인**을 누르세요. 기존 사용자는 오른쪽 위 **⋮ → 환경 점검 · CLI 로그인**에서도 열 수 있습니다. 사용할 AI의 설치와 로그인이 확인되면 다음으로 넘어가세요. 새로 설치한 AI를 찾지 못하면 앱을 다시 열어보세요.

## 2. 부서 만들기

1. **부서 만들기**를 누릅니다.
2. 연습용 폴더나 기존 프로젝트의 복사본을 고릅니다.
3. 부장으로 사용할 AI를 선택합니다. 부장은 목표를 정리하고 팀을 구성하는 AI입니다.
4. 처음에는 허가 방식을 기본값인 **전부 묻기**로 유지합니다.
5. 부서를 만듭니다. AI가 폴더 접근을 확인하면 표시된 경로를 보고 허가 여부를 결정하세요.

## 3. 첫 지시 보내기

화면 아래 부장 입력칸에 다음 문장을 복사해 보내보세요.

> 이 폴더의 프로젝트를 살펴보고 구조와 실행 방법을 설명해줘. 파일은 아직 수정하지 말고, 다음에 할 일을 제안해줘.

AI가 실제로 답하는지 확인한 뒤 작은 수정 작업을 맡겨보세요. 한 번에 많은 팀원을 쓰면 AI 사용량도 늘어날 수 있습니다.

## 4. 진행 상황과 허가 요청 확인하기

- 캐릭터를 누르면 해당 AI의 대화와 작업 기록을 확인할 수 있습니다.
- **내 책상**에는 사용자의 허가나 답변이 필요한 요청이 모입니다. 작업 설명과 영향을 읽고 결정하세요.
- 오류가 나오거나 답변이 멈춘 것 같으면 오류 안내와 해당 멤버의 터미널을 확인하세요. 같은 요청을 반복해서 보내기 전에 이미 실행됐는지 살펴보세요.

이 안내는 앱 오른쪽 위 **⋮ → 처음 사용 안내**에서 다시 볼 수 있습니다.
