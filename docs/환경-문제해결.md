# 픽셀 오피스 문제 해결

[앱 소개](../README.md) · [설치·사용 안내](release/0.1.0/README-KO.md)

## 앱이 실행되지 않을 때

ZIP 전체를 쓰기 가능한 새 폴더에 풀고 실행하세요. 실행 파일만 옮기거나 ZIP 안에서 바로 실행하면 필요한 파일을 찾을 수 없습니다. 보안 프로그램이 파일을 격리했는지도 확인하세요.

코드 서명을 하지 않은 시험판입니다. 내려받은 곳이 공식 배포 페이지인지, ZIP의 SHA256이 배포한 값과 같은지 확인하세요. 개발 도구는 별도로 설치하지 않아도 됩니다.

## AI가 실행되지 않거나 로그인이 필요할 때

1. 상단 메뉴에서 **환경 점검 · CLI 로그인**을 엽니다.
2. 사용할 AI 프로그램의 설치와 로그인 상태를 확인합니다. AI 프로그램과 계정은 별도로 필요합니다.
3. **Claude Code만 사용**, **Codex만 사용**, **Claude Code + Codex 사용** 중 실제 사용하는 조합을 선택합니다.
4. 로그인이 만료됐다면 앱 안의 로그인 기능 또는 해당 프로그램의 터미널에서 로그인합니다.
5. 로그인한 뒤 **로그인 연결 · 요청 재시도**로 연결을 갱신합니다. 사용 중인 업무가 있다면 앱에 표시되는 안내를 먼저 확인합니다.

일반 터미널에서 로그인한 계정은 앱에서도 사용합니다. 터미널과 앱에서 서로 다른 Windows 사용자나 실행 파일을 사용하는지 확인하세요. 원인을 확인하기 전에 로그인 파일이나 작업 기록을 삭제하지 마세요.

## Windows 실행 권한 오류가 날 때

로그인 문제와 실행 권한 문제는 서로 다릅니다. 팝업과 터미널에 표시된 원인을 확인하고, 해당 멤버를 다시 시작한 뒤 **선택 멤버 검사**를 실행하세요. 앱은 Windows 권한을 임의로 변경하지 않습니다. 기존 업무의 실행 결과가 불확실하면 실제 파일과 작업 기록을 먼저 확인하세요.

## 작업이 멈춘 것처럼 보일 때

부장과의 대화·회의·단계 기록에서 현재 단계와 기다리는 대상을 확인하세요. 팀원과 팀장의 일반 질문은 상위 AI가 처리하고, 사용자 판단이나 실행 허가가 필요한 요청은 내 책상에 표시됩니다. 같은 요청을 반복하기 전에 터미널과 보고서에서 이미 실행됐는지 확인하세요.

## 업데이트와 백업

앱을 종료한 뒤 앱 설정 폴더와 프로젝트의 작업 기록을 함께 백업하세요. 새 버전은 별도 폴더에 풀어 실행합니다. 자세한 위치와 복구 순서는 [사용 안내](release/0.1.0/README-KO.md)를 참고하세요.

## 문제가 계속될 때

[문제 제보](https://github.com/MaoEmong/pixel-office/issues)에 앱 버전, Windows 버전, 사용하는 AI 프로그램의 버전, 오류 문구와 발생 순서를 남겨 주세요. 로그인 정보, 연결 키, 원본 설정 파일, 개인 프로젝트 내용은 제외하세요.
