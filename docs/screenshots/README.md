# 픽셀 오피스 스크린샷 갤러리

[프로젝트 소개로 돌아가기](../../README.md)

실제 Windows 앱을 촬영한 **27장**입니다. 사진을 누르면 원래 크기로 볼 수 있습니다.

개인 작업과 로그인 정보를 노출하지 않도록 별도의 소개용 환경에서 촬영했습니다. `픽셀 노트 만들기` 프로젝트, 대화, 회의, 작업 결과, 사용량과 연결 상태는 모두 설명용 예시입니다. **실제 AI가 수행한 작업의 증거 사진이나 성능 측정 결과가 아닙니다.** 터미널 출력에도 예시임을 표시했습니다. 앱 화면을 그림으로 다시 만들거나 내용을 합성하지 않았습니다.
