# 픽셀 오피스 · Pixel Office

<img src="docs/branding/app-icon.png" width="96" height="96" alt="픽셀 오피스 아이콘">

**Claude Code·Codex·Antigravity의 작업을 픽셀 사무실에서 확인하는 윈도우 앱입니다.**

부장 AI에게 목표를 이야기하면 AI가 팀을 구성하고 일을 나눕니다. 사용자는 캐릭터를 눌러 대화와 작업 기록을 보고, 필요한 허가 요청을 ‘내 책상’에서 확인합니다.

[Windows 0.1.4 다운로드](https://github.com/MaoEmong/pixel-office/releases/tag/v0.1.4) · [처음 사용 안내](docs/FIRST-USE-KO.md) · [설치·업데이트](docs/release/0.1.4/README-KO.md) · [검증 범위](docs/release/0.1.4/VERIFICATION.md)

## 사용 전에 확인하세요

- 현재 배포 파일은 **Windows x64 시험판**입니다. macOS·Linux용 파일은 제공하지 않습니다.
- 사용할 AI 프로그램의 **설치와 계정 로그인은 별도**입니다. Claude Code·Codex·Antigravity 중 사용할 것만 준비하면 됩니다. AI 이용 가능 여부·요금·사용량은 각 서비스 조건을 따릅니다.
- 앱 실행에 필요한 Node.js와 기본 구성품은 ZIP에 포함되어 있습니다. Flutter·Visual Studio·npm을 직접 설치할 필요는 없습니다.
- Windows에서 제작자를 확인하는 **코드 서명은 아직 없습니다**. 보안 설정에 따라 경고가 표시되거나 실행이 제한될 수 있습니다.
- 다른 PC에서 처음 설치·로그인하는 과정은 아직 검사하지 않았습니다. 중요한 프로젝트보다 연습용 폴더나 복사본으로 먼저 사용해보세요.

## 처음 시작하기

1. [배포 페이지](https://github.com/MaoEmong/pixel-office/releases/tag/v0.1.4)에서 ZIP을 내려받아 **전체**를 새 폴더에 풉니다.
2. pixel_office.exe를 실행합니다. 실행 파일만 따로 옮기지 마세요.
3. 사용할 AI 프로그램을 설치하고 로그인한 뒤, 첫 화면의 **준비 상태 확인**을 누릅니다.
4. **부서 만들기**에서 작업 폴더와 부장 AI를 고릅니다. 처음에는 기본 허가 방식을 유지하세요.
5. 아래 입력칸에 작은 작업부터 지시합니다. 예: “이 프로젝트의 구조와 실행 방법을 설명해줘. 파일은 아직 수정하지 마.”

![0.1.4 첫 사용 안내 화면](docs/screenshots/28-first-use-014.png)

위 이미지는 0.1.4 앱 화면에 검사 전용 연결 정보를 넣어 촬영했습니다. 실제 AI 작업이나 실제 계정의 실행 결과를 보여주는 화면은 아닙니다.

## 할 수 있는 일

| 하고 싶은 일 | 앱에서 하는 방법 |
|---|---|
| 작업을 맡기기 | 부장과 목표·완료 기준을 정하고 팀 구성을 맡깁니다. |
| 진행 상황 확인 | 사무실의 캐릭터와 대화·회의·작업 기록을 봅니다. |
| 방향 바꾸기 | 작업 중에도 부장에게 질문이나 변경 지시를 보냅니다. |
| 실행 허가 판단 | 내 책상에서 작업 설명·영향·실제 명령을 읽고 허가하거나 거부합니다. |
| 여러 AI 사용 | 사용할 AI를 각각 체크합니다. 부장과 같은 AI만 쓰는 기본 설정도 있습니다. |
| 사용량 확인 | AI 사용량 버튼에 마우스를 올리면 요약, 누르면 상세 정보를 봅니다. 확인하지 못한 수치는 미확인으로 표시합니다. |

**Antigravity 연결·폴더 접근 허가·사용량 표시도 0.1.4에 포함되어 있습니다.** Antigravity 내부 모델 그룹의 사용량은 별도 Claude Code·Codex 계정의 사용량과 다릅니다.

![팀을 배치한 사무실의 기능 소개용 예시](docs/screenshots/01-hero.jpg)

위 사무실 이미지를 비롯한 [기존 스크린샷 27장](docs/screenshots/README.md)은 실제 앱에 소개용 데이터를 넣은 예시입니다. 실제 작업 성과나 계정 정보를 보여주지 않으며, 이전 버전 화면이 포함되어 현재 버튼 배치와 다를 수 있습니다.

## 저장·업데이트·문제 제보

앱 설정은 PC의 앱 데이터 폴더에, 프로젝트별 대화와 작업 기록은 선택한 프로젝트의 .pixel-office 폴더에 저장합니다. 재실행하면 저장된 작업의 복구를 시도하지만, 로그인 만료나 권한 문제는 사용자의 조치가 필요할 수 있습니다.

업데이트 전에는 작업을 마치고 앱을 정상 종료한 뒤 두 데이터 폴더를 백업하세요. 새 ZIP은 기존 설치 폴더에 덮어쓰지 말고 **새 폴더**에 풉니다. [설치·업데이트 안내](docs/release/0.1.4/README-KO.md)

문제 제보는 [GitHub 이슈](https://github.com/MaoEmong/pixel-office/issues)에 앱 버전·사용 AI·오류 문구·재현 순서를 남겨주세요. 계정 정보, 인증 파일, 비공개 프로젝트 내용은 공개하지 마세요.

[문제 해결](docs/환경-문제해결.md) · [선택 기능: 원격 접속](docs/원격접속.md)
